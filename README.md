# Meanwhile: playtest builds

**[Download the Windows installer](https://github.com/rslavin/meanwhile-releases/releases/latest/download/Meanwhile-Setup.exe)**

Run it once. It installs for you alone, with no administrator needed, and starts the game. After that,
the game fetches each new build by itself and puts it in the next time it starts.

Windows may say "Windows protected your PC" the first time, because test builds are not signed yet.
Choose **More info**, then **Run anyway**. Updates do not ask again.

Every build and what changed in it is under [Releases](https://github.com/rslavin/meanwhile-releases/releases).
The game's source is not here; this repository only holds the builds.
